# 🌱 Garden Community Python Exercises

A beginner-friendly Python project focused on a small gardening theme. Each exercise teaches a core programming concept such as input/output, conditions, loops, recursion, and simple functions through a realistic garden management scenario.

This project is designed for learners who want to practice Python in a fun and practical way while building small, understandable programs.

## 📌 Project Overview

The idea is simple: you are managing a small garden community. The exercises help you:

- greet the garden community
- name a garden
- calculate a plot area
- measure harvest totals
- check plant growth stages
- remind when to water plants
- count down to harvest day
- track seed inventory

Each script is a small standalone task that explores a different programming concept.

## 🧩 Exercises Included

| Exercise | File | What it does |
| --- | --- | --- |
| ex0 | `ex0/ft_hello_garden.py` | Prints a warm greeting to the garden community. |
| ex1 | `ex1/ft_garden_name.py` | Asks for a garden name and displays the status. |
| ex2 | `ex2/ft_plot_area.py` | Calculates the area of a garden plot from length and width. |
| ex3 | `ex3/ft_harvest_total.py` | Adds the harvest from three days. |
| ex4 | `ex4/ft_plant_age.py` | Checks whether a plant is ready to harvest based on age. |
| ex5 | `ex5/ft_water_reminder.py` | Warns when plants need water. |
| ex6 | `ex6/ft_count_harvest_iterative.py` | Counts down harvest days using a loop. |
| ex6 | `ex6/ft_count_harvest_recursive.py` | Counts down harvest days using recursion. |
| ex7 | `ex7/ft_seed_inventory.py` | Displays seed inventory information with a unit check. |

## 🚀 Getting Started

Make sure you have Python 3 installed on your machine.

### Run a script

```bash
python3.10 ex0/ft_hello_garden.py
```

You can replace the path with any exercise you want to try.

## 📚 Learning Path

If you are new to Python, try the exercises in order:

1. `ex0` — basic output
2. `ex1` — input and output
3. `ex2` — calculations
4. `ex3` — multiple inputs and totals
5. `ex4` and `ex5` — logic and decisions
6. `ex6` — loops and recursion
7. `ex7` — function arguments and output formatting
